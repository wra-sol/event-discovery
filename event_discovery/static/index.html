How discovery works
  1. Sources — Enabled sites in this list (top to bottom) are crawled in that order.
  2. Politeness — Each source checks robots.txt; the User-Agent and delay above apply.
  3. Fetch — Each site’s URLs are read using the handler type you set under Edit….
  4. Detail pass — If enabled, we may open individual event pages to fill missing dates or venue (still respects robots).
  5. Dedupe — Overlaps across sources are merged automatically.
  6. Score — Keyword and date rules (defaults or per-source overrides) set relevance; results are sorted by score.
